3.1FreeRTOS · STM32F401Flagship

rtos-condition-monitor

A FreeRTOS V11 condition-monitoring node for the NUCLEO-F401RE, written like production firmware. It samples an analog sensor at 100 Hz, computes a 1 s AC-RMS, raises hysteresis alarms and streams CRC-protected telemetry.

  • Analysed task set: exact response-time analysis runs at boot, with budgeted or measured WCETs
  • Zero heap: every kernel object is statically allocated
  • Watchdog that proves liveness: a supervisor feeds the IWDG only while every task checks in
  • Post-mortem: fault records survive reset
  • CI: host tests under ASan/UBSan, cppcheck and a QEMU boot test on every push

3.2ASIC · SKY130RTL → GDSII

32-bit RISC-V SoC with 9-corner signoff

A PicoRV32 RV32I core with a 256-byte boot ROM and a custom memory-mapped 8N1 UART, hardened with LibreLane / OpenROAD on the open SkyWater 130 nm PDK.

  • Verification: a self-checking Icarus testbench boots the SoC from ROM and decodes its serial output in CI
  • Closure: the first run failed placement at 82% utilisation; die resize, cell exclusions, wire-length limits, slew margins and CTS tuning followed
  • Signoff: zero DRC, LVS-clean, zero antenna; setup, hold, slew, cap and fanout clean on all 9 corners
  • Release: GDS, metrics.json and signoff reports published as v2.1

3.3Bare metal · Cortex-M4

IRSense: IR counter & conveyor monitor

STM32F401 firmware that turns a cheap IR obstacle sensor into a measurement instrument for conveyor lines.

  • TIM2 captured in the EXTI ISR gives µs timestamps; the glitch filter adds latency, not error
  • Counter, monitor and guard modes with latched JAM, RATE and INTRUSION alarms
  • Wear-levelled, power-fail-safe flash config with CRC-32 (2,520 saves per erase)
  • 21-command CLI, independent watchdog and reset-cause reporting
